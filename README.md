Personal Expense Tracker

A console-based Personal Expense Tracker built using Java and Object-Oriented Programming.

Features

- Add new expenses
- View all expenses
- Delete expenses
- Calculate total expenses
- Filter expenses by category
- Save and load expenses using file handling
- Persistent storage using a text file

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList and Collections
- File Handling
- VS Code

Project Structure

src/
├── Main.java
├── Expense.java
├── ExpenseManager.java
└── FileManager.java

How to Run

1. Install Java JDK.
2. Clone this repository:
   "git clone https://github.com/Mayank5060/expense-tracker.git"
3. Open the project folder in VS Code.
4. Run "Main.java".
